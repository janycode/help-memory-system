# Triage 标签

这些技能以五个标准 triage 角色表述意图。本文件把角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库的标签       | 含义                        |
| -------------------------- | ------------------ | --------------------------- |
| `needs-triage`             | `needs-triage`     | 维护者需评估该 issue        |
| `needs-info`               | `needs-info`       | 等待报告者补充信息          |
| `ready-for-agent`          | `ready-for-agent`  | 已完整定义，可交给离线 agent |
| `ready-for-human`          | `ready-for-human`  | 需人工实现                  |
| `wontfix`                  | `wontfix`          | 不予处理                    |

当技能提到某个角色（例如【打上 AFK-ready 的 triage 标签】）时，使用上表对应的标签字符串。

如需改用自有词表，只改【本仓库的标签】列，左列保持不动。
